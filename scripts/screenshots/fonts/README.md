# Fonts for the demo artwork

Open fonts under the SIL Open Font License 1.1, copied unchanged from github.com/google/fonts (`ofl/`). They are used only by
`../make-art.py` to set the invented titles on the posters and logos; the licence text of each family is in `licenses/`.

Bebas Neue, Oswald, Cinzel, Playfair Display (roman and italic), Abril Fatface, Anton, Pacifico, Fredoka, UnifrakturCook,
Space Grotesk, Cormorant Garamond, Limelight, Rye, Orbitron, Archivo Black, Lora, Josefin Sans, Bungee, Poiret One.
