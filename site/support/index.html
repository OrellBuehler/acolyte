Support

Acolyte is a one-person project. The best way to get help, report a bug or ask for a feature is a GitHub issue.

Open or search issues

Where to ask

A problem with the app

A crash, a screen that will not load, wrong or missing text, a layout problem, or something that works in the HolyArrs web app but not in Acolyte.

Acolyte issues

A problem with the server

Downloads that do not start, library scans, wrong metadata, server settings. If the same thing fails in the HolyArrs web app in a browser, it is a server matter.

HolyArrs project

A problem connecting

No answer, certificate or host name errors. These are usually settings on the server or the network. See the questions below.

What to put in an issue

  • The platform and its version (for example Android 15, iOS 18.3 or tvOS 18), and the Acolyte version or release you installed.
  • What you did, what you expected and what happened. A screenshot helps if it shows no private details.
  • The HolyArrs server version, if you know it.

Issues are public. Leave out passwords, API keys, session codes and private server addresses. Search the existing issues first; your problem may already have an answer.

Frequently asked questions

What does “unofficial” mean?

Acolyte is written by an independent developer. It is not made, endorsed or supported by the HolyArrs project. It uses the public HolyArrs API, so a new HolyArrs release can occasionally change something before Acolyte has caught up. Please send problems with the app to the Acolyte issues, not to HolyArrs.

Do I need a server of my own?

Yes. Acolyte is only an app for a HolyArrs server that you or someone you know runs. It does not include a server and offers no hosted one.

Which server address do I type?

The address you use to open HolyArrs in a browser, for example 192.168.1.10:6262 or media.example.com. If your server lives under a path such as /holyarrs, include it. If you leave out https:// or http://, the app tries HTTPS first and then HTTP. You can paste a /login or /api/v1 address; the app trims it.

Use HTTPS for a server you reach over the internet. On iPhone and Apple TV plain HTTP only works for addresses on your local network.

The app cannot connect, or shows an error
  • No server answered: check the address and the port, and that your phone is on the same network or VPN as the server.
  • The certificate is not trusted: for a self-signed certificate, install its certificate authority on the device.
  • The server refuses this host name: a name that is not an IP address must be listed in HolyArrs under Settings, Sign-in and security, Allowed host names.
  • This is not a HolyArrs server: check the address and any URL base such as /holyarrs.
  • This server is not set up yet: finish the first-run setup in a browser first.

The HolyArrs documentation has more on connecting when it does not work.

Which ways to sign in work?

A HolyArrs account with password (with a two-factor code or a backup code if the account uses one), a Jellyfin account, an Emby account, Plex, and an API key. Plex needs a browser, so it is available on Android and iPhone but not on Apple TV.

Single sign-on (OIDC) and proxy sign-in are not supported yet. If your server offers one of them, the app tells you so; use your password or an API key instead. Only accounts with the settings permission can create an API key, in the HolyArrs web app under My account.

Why was I signed out?

The server ended the session: it expired, or you signed out somewhere else. The app shows “Your session has ended” and keeps the server address and your user name, so signing in again is quick. If the same address and password worked before and now fail, check that the server is up.

A section is missing

Acolyte shows what your account may use and what your server has switched on. A normal member sees browsing, requests, downloads and the calendar; managers also see history, status, users and settings. If something is missing, ask the person who runs your server about your role and which parts are on.

A trailer does not play

Trailers come from your server, which finds them on YouTube. If the server has none for a title, or cannot play it, the app offers the YouTube link instead and opens it in your browser or the YouTube app.

Is Acolyte in the App Store or Google Play?

Not yet. It is in testing. Builds are published on the GitHub releases page. The Apple TV app is still in development and not in the test builds.

What data does the app collect? How do I delete it?

The developer receives no data from the app. Everything the app keeps is on your device, and signing out or uninstalling removes it as described in the privacy policy.
